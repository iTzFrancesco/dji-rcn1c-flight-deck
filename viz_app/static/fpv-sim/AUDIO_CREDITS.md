# Audio credits

The PC simulator uses one CC0 sound effect from OpenGameArt.org:

- `audio/fan_interval.wav` — “(defect) motor loop”, recorded by qubodup as a graphics-card fan loop.
  Source: https://opengameart.org/content/defect-motor-loop

The file is distributed under CC0. The simulator also has a small Web Audio fallback so the game
remains audible if a browser cannot decode the local sample.
